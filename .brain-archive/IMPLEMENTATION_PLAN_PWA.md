
# Implementation Plan - Phase 50: Offline PWA Architecture

> **Goal:** transform Nucleus HUD into a local-first Progressive Web App (PWA).
> **Target:** `tools/nucleus-hud` (Next.js 16 / React 19)

## User Review Required
> [!IMPORTANT]
> Next.js 16 is a very new/cutting-edge version. We will use `@ducanh2912/next-pwa` which is the standard community fork for ensuring App Router support. Verification of compatibility is the first step.

## Proposed Changes

### 1. Dependencies
- Install `@ducanh2912/next-pwa` (dev dependency or regular?). Regular.

### 2. Configuration (`next.config.ts`)
- Import `withPWAInit` from `@ducanh2912/next-pwa`.
- Wrap the existing configuration.
- Configure `dest: "public"`.

### 3. Manifest (`public/manifest.json`)
- Create standard manifest with:
    - Name: "Nucleus HUD"
    - Short Name: "Nucleus"
    - Start URL: "/"
    - Display: "standalone"
    - Background/Theme colors using standard Nucleus palette (#000000).

### 4. Icons
- Verify `public/icon.png` or `public/file.svg`.
- If missing, we will use a placeholder or Generate one.
- Add `public/sw.js` (generated by build).

## Verification Plan

### Automated Tests
- Run `npm run build` to verify Service Worker generation.
- Check `.next/static/workbox-...` files.

### Manual Verification
- Start `npm run start`.
- usage verification: Open browser.
- Check DevTools > Application > Service Workers.
- Toggle "Offline" mode and refresh. App should load.
