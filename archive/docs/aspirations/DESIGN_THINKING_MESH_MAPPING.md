## The Mapping

### Stage 1: Problem Finding & POV

**Design Thinking:**
- Generate problem ideas
- Filter through 3 categories
- Converge on POV statement (Users/Need/Why)

**Mesh Theory:**
- **Lines active:**
  - Problem exploration MCP (generating ideas)
  - Evidence gathering MCP (filtering)
  - POV synthesis MCP (convergence)
- **Plane:** Problem space definition
- **Intersections:** Where problem ideas meet reality/observability/feasibility
- **Closed shape:** Well-defined POV statement with validated boundaries

**Sequential Thinking:**
- **Loop mechanism:** Each iteration generates new problem dimensions
- **Convergence:** POV statement stabilizes (<1% change)
- **Context accumulation:** Each loop adds evidence → richer POV
- **Frequency:** 5-10 loops (STANDARD) until POV unchanging

## The Recursive Aggregator Connection

### How Design Thinking via Sequential Thinking MCP IS a Recursive Aggregator

**Recursive Aggregator (from your architecture doc):**
- Northbound: Single interface to client
- Southbound: Multiple MCPs coordinated
- Governance: Policies, isolation, audit

- **Northbound:** "Design thinking" as single coherent process to user

## Practical Implications

### 1. You can dial depth at any level

**Whole process:**
- SPRINT: 200-400 turns
- EXHAUSTIVE: 3000+ turns

**Individual stage:**
- Stage 3 (personas) needs more depth? Increase loops for just that stage

**Individual loop:**
- Critical assumption? Do 10 searches instead of 2 for that loop

### 2. You can visualize progress geometrically

**Open shape:** Still exploring, lines haven't converged  
**Closing shape:** Delta decreasing, convergence approaching  
**Closed shape:** <1% delta achieved, ready to proceed  

### 3. You can identify innovation nodes explicitly

**Where are the vertices?**
- POV statement (Stage 1)
- Research plan (Stage 2)
- Each persona (Stage 3)
- Each solution concept (Stage 4)
- Each hypothesis (Stage 5)
- Business model (Stage 6)
- MVE scope (Stage 7)

**These are your decision points. These are where value is created.**

**Anti-duplication in innovation:**

## Example: Full Flow

### Problem: GentleQuest user drop-off

**Stage 1 (POV):**
- Loop 1: Search "habit tracking drop-off rates" → 60-80% typical
- Loop 2: Search "user onboarding psychology" → cognitive load critical
- Loop 3: Challenge assumption: "It's not just tracking, it's motivation"
- Loop 4: POV stabilizes: "Users need low-friction tracking with emotional support"
- Loop 5: Validation loop, <1% change → CONVERGED
- **Mesh:** Problem exploration line + evidence line + feasibility line = POV node

**Stage 2 (Research):**
- Loop 1: Search "extreme users mental health apps" → identify types
- Loop 2: Search "research methodologies behavioral change" → select methods
- Loop 3: Plan access to users via Reddit/support groups
- Loop 4: Validate methods against academic sources
- Loop 5: Research plan stable → CONVERGED
- **Mesh:** User type line + method line + context line = Research plan node

**Stage 3 (Personas):**
- Loops 1-5: Develop "Anxious Achiever" persona
- Loops 6-10: Develop "Burned Out Professional" persona
- Loops 11-15: Develop "Supportive Parent" persona (adjacent)
- Loops 16-20: Cross-validate all three, resolve conflicts → CONVERGED
- **Mesh:** Behavioral plane + emotional plane + contextual plane = 3 persona nodes

**Stage 4 (Solutions):**
- Loops 1-5: Solution 1: Gamification approach
- Loops 6-10: Solution 2: AI emotional support
- Loops 11-15: Solution 3: Community accountability
- Loops 16-20: SCAMPER + prior art + persona validation → CONVERGED
- **Mesh:** Technical line + user need line + market gap line = 3 solution nodes

**Stage 5 (Experiments):**
- Loops 1-5: Hypothesis: "AI support reduces drop-off by 30%"
- Loops 6-10: Design A/B test with 200 users
- Loops 11-15: Define metrics (retention, engagement, satisfaction)
- Loops 16-20: Validate methodology, estimate resources → CONVERGED
- **Mesh:** Rigor line + resource line + value line = Experiment node

**Stage 6 (Business Model):**
- Loops 1-5: Pricing research ($5-15/mo typical)
- Loops 6-10: Channel analysis (App Store, Reddit, therapist referrals)
- Loops 11-15: Unit economics (CAC $20, LTV $120, 6:1 ratio)
- **Mesh:** Customer line + operations line + financials line = BMC node

**Stage 7 (MVE):**
- Loops 1-5: Scope: AI support bot only, no gamification yet
- Loops 6-10: Timeline: 6 weeks dev + 4 weeks test
- Loops 11-15: Budget: $15k (dev) + $5k (test) = $20k
- **Mesh:** Scope line + timeline line + budget line = MVE node

**Stage 8 (Synthesis):**
- Loop 1: Cross-validate all stages
- Loop 2: Resolve contradiction: Solution 2 chosen, but BMC assumed all 3
- Loop 3: Update BMC to reflect Solution 2 only
- Loop 4: Executive summary: GO with AI support MVE
- Loop 5: <1% change → CONVERGED
- **Mesh:** All 7 previous stages converge at synthesis node

**Result:**
- Clear recommendation: Build AI emotional support bot
- Budget: $20k
- Timeline: 10 weeks
- Expected outcome: 30% retention improvement
- Kill criteria: <10% improvement after 4 weeks

**Result:** Reproducible quality, objective outcomes, evidence-based decisions.

- Geometric visualization
