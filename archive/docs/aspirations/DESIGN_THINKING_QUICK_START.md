**For when you need it NOW.**

---

## RULES (No exceptions)

1. **Every loop = 2+ NEW searches** (web/repo/docs with URLs)
2. **Calculate delta** from previous loop (% change)
3. **Cannot proceed** until <1% delta for 2+ loops
4. **Challenge 1 assumption** per loop
5. **Cite everything** [claim] [source]
6. **Show plan FIRST** before any execution

## STAGES

Execute in order. Converge before moving to next.

### Stage 1: Problem Finding (5-10 loops)
- Generate problems
- Filter (is it real? observable? good fit?)
- Converge on POV: Users/Need/Why

### Stage 2: Research Plan (5-10 loops)
- Identify extreme users (novice/expert/adjacent)
- Select methods (interviews/shadowing/POEMS/etc)
- Plan contexts and trust-building

### Stage 3: Personas (10-20 loops)
- Develop 2+ personas per user type
- Document scenarios/frustrations/needs/quotes
- Identify patterns and workarounds

### Stage 4: Solutions (10-20 loops)
- Generate 3-5 solution concepts
- Apply SCAMPER to each
- Research prior art
- Validate against personas

### Stage 5: Experiments (10-20 loops)
- Define testable hypotheses
- Design experiments with metrics
- Identify risky assumptions
- Plan MVE

### Stage 6: Business Model (5-10 loops)
- Map Business Model Canvas
- Validate with market data
- Calculate unit economics

### Stage 7: MVE Plan (5-10 loops)
- Define minimum scope
- Critical path
- Budget/timeline
- Kill criteria

### Stage 8: Synthesis (3-5 loops)
- Cross-validate all stages
- Resolve contradictions
- Executive summary
- GO/NO-GO recommendation
