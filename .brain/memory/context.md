## Product Overview

GentleQuest is an AI-powered mental wellness app featuring:
- **Alex:** Empathetic AI companion (UI name, can be improved)
- **Quest System:** Gamified micro-interventions for habit formation
- **Mood Tracking:** Longitudinal emotional pattern analysis
- **Crisis Detection:** Real-time safety monitoring with geo-specific resources
- **Evidence-Based:** CBT, DBT, ACT techniques with clinical grounding

## Strategic Position

**Differentiation:** Not just a chatbot—an intelligent companion that:
1. **Acts** (function calling → logs moods, starts exercises)
2. **Remembers** (RAG → builds relationship over time)
3. **Learns** (patterns → personalized recommendations)

**Moat:** Proprietary wellness action layer + personalized memory
