# Burnout Recovery Framework: The Dopamine Path

**Problem:** Standard "Burnout" advice (rest, meditation, screen-free time) often makes ADHD burnout *worse* by increasing understimulation (boredom), which further crashes dopamine levels.

---

## 1. Understimulation Burnout (The ADHD Crash)
Unlike neurotypical burnout (caused by *too much* stress), ADHD burnout is often caused by **too much of the wrong input** (low-reward, repetitive tasks) or **lack of novelty.**

| Metric | Neurotypical Burnout | ADHD Burnout |
| :--- | :--- | :--- |
| **Primary Trigger** | Chronic High Cortisol (Stress) | Chronic Low Dopamine (Boredom) |
| **Brain State** | Overwhelmed / Frantic | "Blue-Screened" / Paralyzed |
| **Typical Reward** | Rest / Silence | Novelty / Challenge |
| **GentleQuest Fix** | Meditation / Breathing | **"Dopamine Micro-Dosing" (Quests)** |

---

## 2. Recovery Protocol: "The Ascent"

### Phase 1: Break the Paralysis (Low Barrier)
*   **The "One Item" Quest:** Don't clean the kitchen. Clean *one* spoon.
*   **Interactive Body Doubling:** Luna "sits" with the user. No cameras, just a shared timer and gentle text check-ins.

### Phase 2: Novelty Injection
*   **SCAMPER for Chores:** User picks a task -> GentleQuest suggests a "weird" way to do it (e.g., "Wash dishes while standing on one leg" or "Listen to a murder mystery while folding laundry").

---

## 3. Burnout-Specific Features
1.  **"Blue Screen" Mode:** A one-tap button for when the user is paralyzed.
    *   *Action:* Luna triggers a 1-minute "Chaos Grounding" (intense sensory input like cold water or loud music) to shock the system back to baseline.
2.  **Understimulation Alert:** If the app detects low activity + many opened/closed task lists -> Luna asks: "Are we bored or just tired?"
3.  **Guilt-Free Resume:** No "Day 1" resets. If you've been "Blue-Screened" for a week, Luna greets you with: "Welcome back! I found some cool things while you were resting."

---

## 4. Clinical Alignment
*   **PHQ-9 Monitoring:** Use the "Energy" question (#4) as the primary burnout signal.
*   **CBT-for-ADHD:** Focus on "Behavioral Activation" (getting moving) over "Cognitive Restructuring" (thinking about thinking), which can be too taxing during burnout.
