# User Validation: Interview Script (Week 1)

> **Context:** Before building complex features (Patterns, Cloud Sync), we must validate **Problem-Solution Fit**.
> **Target Audience:** Solo Founders / Heavy LLM Users (r/ClaudeAI, r/LocalLLaMA)
> **Goal:** Confirm that "Context Amnesia" and "Project Fragmentation" are real, painful problems worth paying to solve.

---

## 1. The Setup (Don't Pitch Yet)

**Opening:**
"Hey, I'm working on a tool for solo founders who use Claude/Gemini heavily. Not selling anything yet, just trying to see if my pain points are real."

**Qualification Questions:**
1. "How many active 'projects' do you have going in Claude right now?" (Look for >3)
2. "How often do you hit the 'Project Context Limit' warning?"
3. "Do you ever find yourself copying the same `context.md` file into new chats?"

---

## 2. The Dig (Find the Pain)

**The Context Problem:**
*"Tell me about the last time you started a 'fresh chat' for an existing project. How long did it take to get the AI back up to speed?"*
- [ ] Listening for: "I have to paste 5 files"
- [ ] Listening for: "I just don't context switch because it's too hard"

**The "Where Was I?" Problem:**
*"If you stepped away for 3 days and came back, how do you figure out exactly what to do next?"*
- [ ] Listening for: "I scroll up and read the chat logs"
- [ ] Listening for: "I keep a separate Notion doc"

---

## 3. The Test (Solution Fit)

**The "Magic Wand":**
*"If you could have a file in your project folder—let's call it `.brain`—that automatically updated itself with every major decision you made in chat, would you trust it?"*

**The Pricing Probe:**
*"I'm building a specialized MCP server that does exactly that. Keeps a 'Ledger' of decisions and a 'Memory' of architecture locally.*
*Is that something you'd install via `pip`, or does it need to be a cloud service?"*

---

## 4. Closing (The Ask)

- **If they seem excited:** "I'm looking for 5 beta testers for the `nucleus` CLI. Can I DM you when the 'Solo Founder' template is ready next week?"
- **If they don't care:** "Thanks! Sounds like your current workflow is solid. What's the *one* thing you wish Claude did better?"

---

## Success Criteria
- [ ] 5 Interviews Conducted
- [ ] 3/5 confirm "Context Amnesia" is a top 3 pain point
- [ ] 2/5 ask to join the waitlist/beta
