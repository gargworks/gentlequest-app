## 2. The Strategy: "Come for the Tool, Stay for the Network"

We are adopting a **3-Stage Activation Strategy**.

### Stage 1: Single Player Mode (The "Nintendo" Strategy)
*   **Concept:** Build the "Mario" and "Zelda" of Agents ourselves.
*   **The Killer Apps:**
    1.  `@nucleus/researcher`: Deep Web Search + **Local Obsidian Integration**. (Better than Perplexity).
    2.  `@nucleus/linear`: "Update my Linear tickets based on this git diff" (Better than Linear bot).
*   **Why it works:** Users install Nucleus just to get *these tools*. The "Marketplace" is secondary.

### Stage 2: Multiplayer Mode (The "Slack" Strategy)
*   **Concept:** Private Registries for Teams.
*   **Scenario:** A Lead Dev creates a `deploy-prod` agent that adheres to strict company policy.
*   **Pain:** Sharing scripts via Git/Wiki is high friction.
*   **Gain:** `nucleus install @company/deployer`.
*   **Why it works:** Viral adoption within engineering organizations.

### Stage 3: Network Mode (The "App Store" Strategy)
*   **Concept:** Public Stranger-to-Stranger Marketplace.
*   **Trigger:** Once we have 10k users from Stage 1 & 2, external devs will have an incentive to publish.
*   **Constraint:** We do NOT focus on this until Stage 1 is rock solid.
