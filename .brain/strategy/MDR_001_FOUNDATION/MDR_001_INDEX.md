## Core Insights

1. **The Swiss Army Knife Problem:** Don't give 50+ tools to a Poet (Chatbot). Route intent to specialized agents.

2. **The Whiteboard Principle:** Users write files because it's flow state. Tools feel like Jira tickets.

3. **The Partner Moat:** Clone the code, can't clone the context. Intimacy is the value.

4. **The Serverless Mind:** Agents are not employees. They are ephemeral compute units spawned and terminated.
