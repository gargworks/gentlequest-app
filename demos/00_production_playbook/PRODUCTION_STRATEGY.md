# Nucleus Demo Trilogy: Production Strategy

**Status:** Active Schema
**Last Updated:** February 14, 2026
**Reference Script:** `MASTER_LOOM_SCRIPT.md`

## 1. Core Doctrine: The "Modular Master"
We do not produce three separate videos. We produce **One Master Timeline** (~2m 15s) that tells a continuous story, which is then sliced into three standalone engagement assets.

### The Trilogy Structure
| Segment | Duration | Theme | Narrative Role |
| :--- | :--- | :--- | :--- |
| **A: Startup** | 0:00 - 0:45 | **Trust** | The "Governance Moat" (Safety) |
| **B: Context** | 0:45 - 1:30 | **Brain** | The "Forensic Audit" (Memory) |
| **C: Sovereign**| 1:30 - 2:15 | **Power** | The "Recursive Mount" (God Mode) |

### The "Clean Breaker" Rule
*   Between each segment, insert a **1-second "Breaker"** (Black screen or Glitch Transition).
*   **Why?** Allows for "Lossless Slicing" to vertical shorts without remixing audio.

---

## 2. Narrative Strategy: "Frankie"
**Persona:** "Frankie" (The Natural)
**Tone:** Confident, slightly fast, "I see everything." Not a sales pitch. A revelation.
**Key Motif:** "Safety -> Memory -> Power."

### The "Loom" Style
*   No corporate polish. No stock music.
*   **Audio:** Voiceover + Subtle "ASMR" Keyboard Clacks + Glitch SFX on key moments (Lockout/Snap).
*   **Visuals:** Raw Screen Capture. No fancy motion graphics overlays unless they look like part of the terminal.

---

## 3. Visual Strategy: Vertical Adaptation
Because the Nucleus UI is wide (Terminal Left + Claude Right), we cannot use center-cropping.

### The "Split Zone Stack" (9:16)
For TikTok/Shorts/Reels, stack the two active zones:

*   **Top 50%: The Agent (Claude UI)**
    *   *Content:* The "Response", the "Summary", the "Thinking".
    *   *Why:* This is where the human eye looks for intelligence.
*   **Bottom 50%: The Source (Terminal)**
    *   *Content:* The "Command", the "Logs", the "Truth".
    *   *Why:* This anchors the demo in technical reality.

*   *Rule:* Never Pan-and-Scan. It causes motion sickness in code demos.

---

## 4. Production Workflow (Batch)
1.  **Forensics:** Extract frames at 0.33 FPS. Identify key "Truth Moments" in the raw footage.
2.  **Storyboard:** Map the narrative to the timestamps (see `STORYBOARD.md` files).
3.  **Voiceover:** Record the `MASTER_LOOM_SCRIPT.md` in one take.
4.  **Assembly:**
    *   Lay down the VO track.
    *   Cut the "Truth Moments" to the beat of the VO.
    *   Apply "Time Warp" (400% - 800%) to silence/loading spinners.
    *   **Do not cut the "Truth".** (Never speed up the actual result appearing).
