# Counselor Alert System API Documentation

## Overview
The Counselor Alert System enables CAPS (Counseling and Psychological Services) staff to monitor and respond to crisis alerts generated by the AI agent.

## Authentication
Currently protected by network level security (Internal Tool). Future iterations will use Counselor Auth via JWT.

## Endpoints

### 1. Get Alert History (Dashboard)
Fetch a paginated list of alerts for a specific university.

- **URL:** `/api/alerts/history`
- **Method:** `GET`
- **Query Parameters:**
  - `university_id`: Integer (ID of the university)
  - `status`: `pending` or `acknowledged`
  - `severity`: `low`, `medium`, `high`, `critical`
- **Response (200 OK):**
  ```json
  {
    "alerts": [
      {
        "id": 55,
        "session_id": "sess_123...",
        "severity": "high",
        "trigger_message": "Self-harm keywords detected.",
        "sent_at": "2026-01-17T10:00:00",
        "acknowledged_at": null,
        "acknowledged_by": null,
        "email_sent": true,
        "sms_sent": false
      },
      ...
    ],
    "count": 5
  }
  ```

### 2. Get Alert Detail
Fetch full details including conversation context and risk keywords.

- **URL:** `/api/alerts/<alert_id>`
- **Method:** `GET`
- **Response (200 OK):**
  ```json
  {
    "alert": { ... },
    "conversation": [
      { "role": "student", "content": "I feel lost...", "timestamp": "..." },
      { "role": "luna", "content": "I'm here for you...", "timestamp": "..." }
    ],
    "acknowledgments": [
      { "counselor_id": "admin", "notes": "Called student.", "timestamp": "..." }
    ]
  }
  ```

### 3. Acknowledge Alert
Mark an alert as handled.

- **URL:** `/api/alerts/<alert_id>/acknowledge`
- **Method:** `POST`
- **Body:**
  ```json
  {
    "counselor_id": "counselor_1",
    "response_notes": "Student contacted via phone.",
    "action_taken": "phone_call"
  }
  ```
- **Response (200 OK):** `{"success": true}`

## Logic
- **Rate Limiting:** Alerts are de-duplicated if sent within the last hour unless severity increases.
- **Delivery:** Alerts trigger SendGrid (Email) and Twilio (SMS for Critical).
