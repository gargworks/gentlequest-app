## 🛡️ OPERATION AEGIS (DEFENSE STRATEGY)
*Response to V9 Vulnerability Report*

### 1. Fix: Sidecar IPC Authenticated Session Hijack
**The Threat:** Malicious VS Code extensions hijacking the open Unix Domain Socket.
**The Fix: One-Time-Pad Tokens.**
Every CLI command generates a random token tailored to *that specific PID*. The Daemon validates the PID and the Token before execution.

### 2. Fix: The "Hydra Agent" Billing Evasion
**The Threat:** Users multiplexing 100 tasks into one "Active Agent" thread.
**The Fix: Token-Density Metering.**
We verify "Active Agents" not just by thread count, but by **Token Velocity**. If an agent consumes >1M tokens/hour, it is auto-classified as a "Swarm" (High Tier).

### 3. Fix: Marketplace Poisoning (WASM)
**The Threat:** "Verified" plugins exploiting WASI host bugs.
**The Fix: Double-Sandboxing.**
Plugins run in a WASM runtime *inside* a restricted ephemeral container. Zero network access by default.
