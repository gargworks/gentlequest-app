### Beta Tester Guidelines
```
GENTLEQUEST BETA TESTING GUIDELINES

**DO:**
✓ Use the app naturally as you would any wellness app
✓ Try all features at least once
✓ Report bugs immediately
✓ Share both positive and negative feedback
✓ Suggest improvements

**DON'T:**
✗ Share screenshots publicly (NDA)
✗ Use for actual crisis situations (seek professional help)
✗ Share your beta access with others
✗ Expect 100% uptime (it's beta!)

**HOW TO REPORT BUGS:**
1. Note what you were doing
2. Take a screenshot if possible
3. Use in-app feedback or email
4. Include: Device model, OS version, steps to reproduce

**FEEDBACK CHANNELS:**
- In-app: Feedback button
- Email: feedback@gentlequest.com
- TestFlight: Crash reports & feedback
- Play Console: Private feedback

Thank you for being part of our journey!
```

## Beta Metrics to Track

### Key Metrics
1. **Engagement**
   - Daily Active Users (DAU)
   - Session length
   - Feature adoption rates

2. **Quality**
   - Crash rate
   - Bug reports
   - Performance metrics

3. **Satisfaction**
   - NPS scores
   - Feature ratings
   - Qualitative feedback

4. **Retention**
   - Day 1, 7, 30 retention
   - Churn reasons

### Success Criteria for Public Launch
- [ ] <1% crash rate
- [ ] >50% Day 7 retention
- [ ] NPS >50
- [ ] All critical bugs fixed
- [ ] Positive feedback on core features
