## How to Work with AI Agents Effectively

### 1. Batch Similar Tasks
❌ One Reddit post at a time  
✅ "Draft 10 Reddit posts for r/mentalhealth, r/anxiety, r/selfimprovement"

### 2. Provide Context Once
❌ Re-explain product every session  
✅ Reference existing docs: "Use STRATEGIC_AI_CAPABILITIES_ROADMAP.md for positioning"

### 3. Review, Don't Redo
❌ Rewrite agent's work from scratch  
✅ "Adjust tone to be more personal" / "Add specific metric: 45% retention"

### 4. Parallelize Threads
❌ Wait for backend to finish before strategy work  
✅ Run multiple threads simultaneously

### 5. Weekly Syncs
- Each thread should be self-contained
- You synthesize insights across threads weekly
- Cross-pollinate learnings (e.g., user feedback → product decisions)
