# 📣 IndieHackers Promotion Checklist

## Pre-Post
- [ ] **Profile Polish**: Ensure IndieHackers profile has a photo and "GentleQuest Founder" bio.
- [ ] **Screenshot Prep**: Export 3 high-res screenshots of the App (Home, Chat, Quest).
- [ ] **Video**: Have the 2-minute Loom link ready.

## Posting (The "Golden Hour")
- [ ] **Time**: Post at 8:00 AM PST (Peak traffic).
- [ ] **Tags**: Select `Building in Public`, `Technical Founder`, `Mental Health`.
- [ ] **Group**: Post to the "Product Support" or "Side Projects" group.

## Engagement (First 2 Hours)
- [ ] **First Comment**: Add a comment immediately with the "Technical Deep Dive" link (your architecture doc).
- [ ] **Twitter Crosspost**: Share the IH link on Twitter: "Just launched the story behind GentleQuest on @IndieHackers! 👇"
- [ ] **Reddit Crosspost**: Post to r/SideProject with the same text, linking to the IH post for discussion.

## Follow-up
- [ ] **Reply to All**: Reply to every single comment within 1 hour.
- [ ] **dm_leads**: If someone offers specific help, move to DM.
