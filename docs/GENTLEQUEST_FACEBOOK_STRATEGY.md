# GentleQuest Facebook Growth Strategy & Agent Protocols

> **Goal:** Recruit beta testers and build community without triggering "spam" filters or damaging brand reputation in sensitive mental health groups.
> **Owner:** Comet (Browser Agent) / Founder

---

## 1. The "Zero-Spam" Mandate

Facebook Groups are tighter than Subreddits. Admins ban first, ask questions later.
**Core Rule:** Never post a link in the first post/comment unless explicitly asked or allowed by group rules.

---

## 2. Profile & Identity Guardrails

**Identity:**
- Use the **Personal Founder Account** (or "GentleQuest" Page only where allowed).
- **Bio/Intro:** Must clearly state "Building GentleQuest" to be transparent.
- **Safety:** Do NOT use a fake name that sounds like a bot. Use a real-sounding name (e.g., "Lo G." or "Lokesh Builder") if maintaining some privacy.

---

## 3. Group Joining Protocol (Warm-Up Phase)

**Cadence:**
- **Day 1:** Join 3 groups. Do NOT post. Like 2-3 posts.
- **Day 2:** Join 2 more groups. Comment on 1 post (Value only).
- **Day 3:** First "Value Post" or "Feedback Request" in the *friendliest* group.

**Target Groups:**
1.  **ADHD Adults/Support** (High relevance, strict rules)
2.  **Anxiety Support** (High relevance, very sensitive)
3.  **Wellness/Mindfulness** (Lower relevance, looser rules - good for testing)

**Agent Instruction (Comet):**
> "When joining, if asked 'Why do you want to join?', answer: 'I have anxiety myself and am building free tools to help the community. Looking to learn and share techniques.'"

---

## 4. Posting Protocols

### The "Feedback Request" (Safe)
*Used for recruitment. Focuses on "Building" not "Selling".*

> "Hey everyone, I'm building a free tool to help with panic attacks (using grounding techniques). I don't want to spam, but would love valid feedback from 5 people to see if it's actually helpful. Is it okay to share a screenshot here?"
>
> *(Wait for comments saying "Yes" → Then reply with details/DM)*

### The "Value Drop" (Karma Building)
*Text-only. No links. No product mention.*

> "My therapist taught me the 5-4-3-2-1 grounding method, but I always forget the order. I made a sticky note for my monitor. What helpful reminders do you guys use?"

---

## 5. Interaction Rules (The "Comet" Persona)

**When Commenting:**
1.  **Empathy First:** Validate their struggle. "That sounds incredibly hard."
2.  **Share, Don't Solicit:** "I used to struggle with that too. Box breathing helped me." (Do NOT say "My app features box breathing").
3.  **Disclosure:** If they ask about the app, say: "Full disclosure, I'm building a tool for this (GentleQuest), but honestly simple pen and paper works too for some."

**Red Lines (AUTO-ABORT):**
- ❌ Promoting in "Crisis/Suicide" threads.
- ❌ Posting the same text in >2 groups on the same day.
- ❌ DMing admins unless necessary.
- ❌ Linking to the App Store directly in main posts.

---

## 6. Execution Checklist (Next 7 Days)

- [ ] **Setup:** Optimize Profile (Bio + Cover Photo).
- [ ] **Warm-up:** Join 3 groups, 0 posts.
- [ ] **Value:** Drop 1 text-only tip in the most active group.
- [ ] **Recruit:** "Soft" feedback request in IndieHackers/Builder groups (Safer).
- [ ] **Recruit:** "Hard" feedback request in Facebook Groups (Only after Day 3).

---

## 7. Crisis Protocol

If a user expresses self-harm or severe crisis:
- **Do NOT** offer the app.
- **Do NOT** try to counsel.
- **Report** the post to Facebook/Group Admins so they can handle it safely.
- **Disengage**.
