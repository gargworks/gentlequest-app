# Nucleus Growth Strategy & Positioning

> **Product:** Nucleus (CLI Tool / MCP Server)
> **Value Prop:** "Persistent Context Memory for AI Agents"
> **Target:** Solo Founders, Devs using Cursor/Windsurf/Claude

---

## 1. Core Positioning

**The Problem:** "Context Amnesia."
- "I have to copy-paste `context.md` into every new Claude chat."
- "My agent forgot the architecture decision we made yesterday."

**The Solution:**
- A `.brain` folder in your repo that acts as a permanent Ledger.
- `nucleus push "Refactored auth"` → Updates the brain.
- New Chat → Agent reads `.brain` → Instantly smart.
