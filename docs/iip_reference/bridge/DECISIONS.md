# Decisions: Using IIP Materials

Track what is adopted from the IIP reference materials and what is intentionally ignored.

## Adopt
- POV statement format (Who/What/Why) for consistent problem framing.
- Interview capture template + bias reflection.
- Lightweight persona format (2–3 primary personas).
- Experiment template for validating major product bets.

## Do not adopt (as-is)
- The “team research platform” data model and API endpoints as GentleQuest requirements.
- Course-specific submission mechanics (e.g., Blackboard deadlines).

## Open questions
- Should research artifacts live only in `/docs`, or also be stored in-app (admin-only)?
- If stored in-app: what is the minimum schema needed?
