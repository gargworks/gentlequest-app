# Gap Map: IIP Spec → GentleQuest

This file maps the IIP-course entities/artifacts to what exists (or does not) in the current GentleQuest codebase.

| IIP artifact/entity | Purpose in IIP | GentleQuest equivalent | Decision/status |
|---|---|---|---|
| Team / TeamMember | Coordinate student project teams | N/A (GentleQuest is not a team-research tracker) | Not applicable |
| POV Statement (Who/What/Why) | Define the problem clearly | Product strategy/problem framing docs | Adopt as a lightweight template |
| ResearchInterview + ANRUM | Capture user research learnings systematically | Informal feedback today | Add a structured template/process |
| Persona | Summarize archetypes from research | No formal personas today | Optional but useful |
| CVP Canvas (JTBD, pains/gains) | Clarify value proposition | Strategy/roadmap docs | Document at least once |
| Experiment | Hypothesis-driven validation | Ad-hoc testing | Formalize for key bets |

## Notes
- The IIP package describes a course workflow (Weeks 2–11) and a sample “research platform” data model; it should be used as inspiration, not treated as product requirements.
