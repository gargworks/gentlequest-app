# Week 2 — Problem finding → selection → POV

## Template (guide)

### Step 1 — Problem finding (solo)

- Generate a wide set of problem ideas.
- Avoid referencing solutions.

### Step 2 — Problem selection (team)

Use three filters:
- Category 1: Is it real?
- Category 2: Can you observe it?

Format:
- **Users (Who):** …
- **Need (What):** …
- **Why it matters (Why):** …

# Week 7 — Solution concept development

## Template (guide)

### Goal

Develop a testable solution concept by:
- Blueprinting a value-adding process.
- Diverging into components.
- Converging via clustering + SCAMPER.
- Documenting assumptions/uncertainties for Week 8 prototyping.

### Phase I (teamwork)

#### Step 1 — Select a value-adding process to blueprint

- Return to compiled insights and business context (Week 6).
- Review value-added processes associated with the primary HMW.
- Create/copy sticky notes representing three processes.
- As a team, select one process to blueprint.
- If unsure, select based on an assumption; document assumptions and uncertainties.

#### Step 2 — Summarize steps in the process

Summarize, at a high level, the value-added steps required for the selected process.

#### Step 3 — Blueprint three most value-added steps

- Blueprint 3 steps from the summarized process.
- Steps do not need to be contiguous.
- Focus on the most value-added steps.
- Objective: deep dive to uncover innovation opportunities.

#### Step 4 — Solo brainstorm solution components

- Return to the team blueprint.
- Identify innovation opportunities across swim lanes and steps.
- Generate solution components (blue-sky divergence).
- Strategy: reduce complexity through decomposition.

#### Step 5 — Team: cluster components into feasible solutions

- Synthesize divergent components from each team member.
- Cluster and combine into multiple feasible solutions.
- Be prepared to iterate.
- For each clustered solution, document:
  - Assumptions.
  - Unanswered questions.

### Phase III (teamwork, after Week 7 live session)

#### Step 6 — Review feedback and revise HMW

- Each team member reviews teaching team feedback on HMW questions.
- Team discusses and synthesizes reflections.
- Revise selected HMW or select a different HMW.

#### Step 7 — Select one feasible solution cluster to SCAMPER

- Select one clustered solution from Step 5.
- List all components in the selected solution.
- Apply SCAMPER to each component:
  - Substitute
  - Combine
  - Adapt
  - Modify
  - Put to use
  - Eliminate
  - Reverse

#### Step 8 — Document assumptions

Document:
- Remaining unanswered questions about the SCAMPERed solution.
- Aspects you are most unsure about.
