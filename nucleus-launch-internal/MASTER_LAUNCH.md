## Response Templates

### Positive Comment
```
Thank you! Really appreciate it. What's your current multi-tool setup? Would love to hear what features would be most valuable for your workflow.
```

### Technical Question
```
Great question! [Detailed answer]. The relevant code is in `src/mcp_server_nucleus/__init__.py` if you want to dig deeper. Happy to elaborate!
```

### Comparison Question ("How is this different from X?")
```
Good question! [X] is great for [X's use case]. Nucleus focuses specifically on syncing DIFFERENT AI tools together - so you can use Claude + Cursor + Windsurf with one shared brain. They solve different problems and can potentially work together.
```

### Feature Request
```
Love this idea! Added to our roadmap: [link to GitHub issue if created]. PRs welcome if you want to take a crack at it!
```

### Skeptical/Critical Comment
```
Fair point! You're right that [acknowledge the valid concern]. We're approaching it this way because [reasoning]. Open to alternative approaches - what would you suggest?
```

## Emergency Playbook

### If Post Gets Buried
- Don't spam repost
- Iterate on title/messaging
- Try different subreddit or time
- Consider if the problem statement resonates

### If Negative Reception
- Don't get defensive
- Thank people for feedback
- Acknowledge valid criticisms
- Take notes for future iterations

### If Technical Issues Reported
- Acknowledge immediately
- Create GitHub issue
- Fix promptly if possible
- Update with fix status
