## 2. glama.ai (glama.ai/mcp/servers)
**Submission Name:** Nucleus
**GitHub Repo:** https://github.com/eidetic-works/mcp-server-nucleus
**Short Description:** Federated agent memory and governance layer. 100% local, MIT licensed.
**Long Description:** 
Nucleus is a universal brain for AI agents. It provides a standard way to store and retrieve agent context ("Engrams") across multiple IDEs and chat interfaces. 

Unlike SaaS-based solutions, Nucleus is entirely local-first. It includes a Hypervisor layer for secure resource locking and full audit trails, ensuring that agents only see and touch what they are authorized to.

**Differentiator:** No API keys, no cloud sync, Git-native architecture.
