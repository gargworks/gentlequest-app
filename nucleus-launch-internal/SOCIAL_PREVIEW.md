### Colors
- Background: Dark (#0d1117 - GitHub dark)
- Primary text: White (#ffffff)
- Accent: Blue (#58a6ff) or Purple (#8b5cf6)
- Icons/logos: White or accent color

### Elements
1. Brain emoji or custom brain icon (top left)
2. "NUCLEUS MCP" in bold
3. Tagline: "The Universal Brain for AI Agents"
4. Visual showing Cursor ↔ Nucleus ↔ Claude ↔ Windsurf connection
5. `pip install nucleus-mcp` command
6. GitHub URL

### Tools to Create
- Figma (free)
- Canva (free)
- Or use existing demo video thumbnail

## How to Set

1. Go to https://github.com/eidetic-works/nucleus-mcp
2. Settings → General → Social preview
3. Upload the 1280x640 image
