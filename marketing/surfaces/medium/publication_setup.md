# GentleQuest Medium Publication Setup

## Publication Name
**The Gentle Quest**

## Tagline
Small daily experiments in calm, focus, and self-kindness.

## Description (Medium "About" field, 160 chars)
A publication for quiet builders, anxious overthinkers, and anyone who wants to practice wellbeing in small, repeatable ways. No hype. Just gentle experiments.

## Long Description (Publication Info Page)
The Gentle Quest is a reader-supported publication exploring everyday mental wellness through tiny, testable habits. We publish essays on journaling, mood tracking, reflection prompts, and the quiet science of self-compassion. Our pieces are cross-syndicated from gentlequest.app and original to Medium. We believe mental health support should be accessible, private, and never shame-based.

## Publication Rules (Pinned "Submission Guidelines" story)
1. Original or cross-posted content only. If cross-posted, the canonical link to gentlequest.app must appear at the bottom.
2. No medical advice. Any piece touching diagnosis, medication, or clinical treatment must end with: "This is not a diagnosis. Please see a qualified professional."
3. No personal identity references to the founder, team, or any individual by name.
4. No affiliate links. No sponsored placements disguised as essays.
5. Tone: warm, practical, low-pressure. No urgency language ("act now," "you must," "stop doing this").
6. Every piece must include the three platform links (iOS, Android, Web) in the footer.
7. Tags limited to 3 per story, chosen from the approved tag list below.

## Approved Tags
`Mental Health`, `Self Improvement`, `Journaling`, `Mindfulness`, `Productivity`, `Wellness`, `Self Care`, `Anxiety`, `Habit Building`, `Reflection`, `Mood Tracking`, `Digital Wellness`

## Admin Setup
1. Create the publication at medium.com/new-publication.
2. Set publication name: "The Gentle Quest"
3. Upload a neutral logo (soft gradient, no faces, no names).
4. Add publication description (160-char version above).
5. Configure publication domain: leave default `medium.com/the-gentle-quest` unless a custom subdomain is purchased.
6. Invite writers via email; set roles: Editor (can publish), Writer (can submit for review).
7. Pin the "Submission Guidelines" story as the publication's featured story.
8. Enable "Allow cross-posting with canonical URL" in publication settings.
9. Connect publication to Twitter/X for auto-share on publish.
10. Set publication email digest to weekly.
