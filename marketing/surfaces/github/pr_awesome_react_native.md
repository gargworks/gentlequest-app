### Description

GentleQuest is a cross-platform journaling and mood-tracking app with a focus on privacy, low-friction daily habits, and evidence-informed design.

**Key features:**
- One-tap mood logging with optional notes
- Structured reflection prompts (morning, evening, weekly review)
- Self-compassion guided protocol
- Mood and energy trend visualization
- Local-first, encrypted, on-device storage
- No account, no cloud, no analytics

**Technical highlights relevant to the React Native community:**
- Cross-platform deployment from a single codebase (iOS + Android)
- Local encrypted storage implementation
- Offline-first architecture with no network dependency
- Sub-15-second quick-entry UX flow
- Adaptive UI for phone and tablet

### Why it fits this list

awesome-react-native showcases notable applications built with React Native. GentleQuest is relevant because:

1. **Production app:** Real users, real deployment, real App Store and Play Store presence.
2. **Health & wellness category:** Demonstrates React Native's capability in a domain with specific UX requirements (low friction, high privacy, offline reliability).
3. **Local-first architecture:** Shows how React Native can be used for privacy-preserving apps with no backend dependency — an increasingly important pattern.
4. **Cross-platform consistency:** Same experience on iOS and Android from one codebase.
