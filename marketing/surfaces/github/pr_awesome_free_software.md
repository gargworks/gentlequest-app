### Description

GentleQuest is a free journaling and mood-tracking application that embodies the principles of free software in the mental health space.

**Free software principles:**
- **Free to use:** All core features — mood tracking, journaling, reflection prompts, weekly reviews, trend visualization — are available at no cost. No subscription, no freemium paywall on essential features.
- **No vendor lock-in:** Data export in standard formats. Users can leave at any time and take their data with them.
- **User control:** Local-first architecture means users control their data. No server dependency, no account requirement, no remote access to user content.
- **No surveillance:** No analytics, no tracking, no telemetry, no advertising. The app does not monitor user behavior.
- **Privacy by design:** Encrypted on-device storage. The default configuration sends zero data to any server.

**Features:**
- One-tap mood logging with notes
- Structured reflection prompts (morning, evening, weekly review)
- Self-compassion guided protocol
- Mood and energy trend charts
- Sensory prompt sets for low-energy/numb days
- Three-breath reset micro-practice
- Data export in standard format

### Why it fits this list

awesome-free-software curates software that respects user freedom. GentleQuest aligns with these principles:

1. **Free as in cost:** No payment required for any core feature. Mental health tools shouldn't be paywalled.
2. **Free as in control:** Local-first storage means users retain control of their data. No company can revoke access, change terms, or shut down the service and lose user data.
3. **Free as in privacy:** No surveillance, no data harvesting, no advertising model. The app's incentives are aligned with the user's, not against them.
4. **No lock-in:** Standard format export ensures users can migrate to other tools without losing their journal history.
