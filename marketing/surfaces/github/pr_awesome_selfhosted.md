### Description

GentleQuest is a privacy-focused journaling and mood-tracking app designed around low-friction daily habits. It provides structured reflection prompts, mood logging, and weekly reviews — all stored locally on the user's device with encryption.

### Why it fits this list

- **Local-first architecture:** All journal entries and mood data are stored on the user's device. No cloud server is required for core functionality. This aligns with the self-hosted ethos of data ownership and privacy.
- **No account required:** Users can use the app without creating an account, providing an email, or connecting to any external service.
- **Offline by default:** The app works fully offline — reading, writing, and reviewing entries requires no internet connection.
- **Data export:** Users can export their data in standard formats at any time, ensuring no lock-in.
- **Privacy-preserving:** No analytics, no tracking, no third-party SDKs that phone home.

### License

The app is available on iOS, Android, and web. The web version is accessible at https://gentlequest.app. The app is free to use.
