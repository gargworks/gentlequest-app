### Description

GentleQuest is a cross-platform journaling and mood-tracking application built with Flutter. It demonstrates several Flutter best practices:

- **Cross-platform from a single codebase:** iOS, Android, and web from one Flutter project.
- **Local-first data architecture:** On-device encrypted storage using Flutter's local storage solutions. No backend server required for core functionality.
- **Offline-first design:** Full app functionality without network connectivity.
- **Responsive UI:** Adaptive layouts that work across phone, tablet, and web.
- **Low-friction UX:** Quick-entry flows optimized for sub-15-second interactions — a design challenge that showcases Flutter's animation and state management capabilities.
- **Structured prompt system:** Dynamic prompt generation based on time of day and user state, demonstrating Flutter's local state management patterns.

### Why it fits this list

awesome-flutter showcases notable Flutter applications. GentleQuest is a good fit because:

1. **Real-world Flutter app:** Not a demo or template — a production app serving real users across three platforms from a single codebase.
2. **Health & fitness category:** Demonstrates Flutter's capability in the wellness/health app space, which has specific UX and data handling requirements.
3. **Privacy-focused architecture:** Shows how Flutter can be used for local-first, offline-first applications — an important pattern for privacy-sensitive apps.
4. **Cross-platform consistency:** The same codebase produces native iOS, Android, and web experiences.
