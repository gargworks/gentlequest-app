# GentleQuest vs Woebot: perbandingan detail

Jika Anda membandingkan Woebot dengan GentleQuest, Anda mencari alat kesehatan mental yang tepat.

## Apa itu Woebot

Woebot adalah aplikasi kesehatan/kesejahteraan populer.

## Kekuatan Woebot

- Desain mudah digunakan
- Variasi fitur
- Mapan di bidangnya

## Kelemahan Woebot

- Langganan diperlukan
- Gamifikasi — streak bisa menekan
- Akun diperlukan
- Data di cloud
- Tanpa alat skrining

## Apa yang berbeda dari GentleQuest

- **Tanpa langganan** — semua gratis
- **Tanpa streak** — check-in kapan saja
- **Tanpa akun**
- **Privasi di perangkat**
- **Alat skrining** — PHQ-9, GAD-7, dll.
- **Sumber krisis**

## Perbandingan fitur

| Fitur | Woebot | GentleQuest |
|---------|-------------------|-------------|
| Model harga | Variabel | Gratis, tanpa langganan |
| Akun diperlukan | Variabel | Tidak |
| Iklan | Variabel | Tidak |
| Streak/Gamifikasi | Variabel | Tidak |
| Penyimpanan data | Variabel | Di perangkat |
| Alat skrining | Variabel | Ya |
| Alat grounding | Variabel | Ya |
| Jurnal | Variabel | Ya, di perangkat |
| Sumber krisis | Variabel | Ya |

## Kesimpulan

Tidak ada aplikasi yang "lebih baik" secara objektif — melayani kebutuhan berbeda.

## Di mana GentleQuest cocok

GentleQuest menawarkan check-in suasana hati, alat penjangkaran, jurnal, dan kuesioner skrining tervalidasi dalam satu aplikasi yang tenang dan privat — tanpa iklan, tanpa rentetan, tanpa langganan, tanpa akun. Data Anda tetap di perangkat Anda.

- iOS — https://apps.apple.com/app/gentlequest/id6756537464
- Android — https://play.google.com/store/apps/details?id=com.gentlequest.app
- Web — https://gentlequest.app
