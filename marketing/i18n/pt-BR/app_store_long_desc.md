# GentleQuest — App Store Long Description

GentleQuest é um companheiro de saúde mental gratuito e privado para adultos 18+.

Desabafe. Um chat tranquilo que escuta sem julgar.

Registre seu humor. Cinco segundos por dia. Sem sequências. Sem culpa.

Monte um plano de segurança. Linhas de crise para o seu país. Pessoas em quem você confia, a um toque de distância.

Pequenas missões. Exercícios de TCC de 90 segundos. Respiração, ancoragem, registros de pensamentos. Você vai superá-los. Esse é o objetivo.

Diário. Página em branco, sem instruções. Nenhuma IA lê. Nenhuma IA resume. Só seu.

Seus dados são seus. Exporte quando quiser. Delete quando quiser. Modo anônimo.

Sem anúncios. Sem venda de adicional. Sem paywall. Sem rastreamento. Sem sequências.

Grátis. 18+. Só isso.

Não é um diagnóstico. Não é um terapeuta. Uma ponte. Consulte um profissional para diagnóstico.
