# Relaxamento muscular progressivo passo a passo: libere tensão

PMR é uma técnica baseada em tensionar e relaxar sistematicamente grupos musculares. É simples, leva 10-15 minutos.

## O que é PMR?

Para cada grupo muscular: tensionar 5-7 segundos, relaxar 15-20 segundos.

## Por que funciona

### Ciclo tensão-ansiedade
O estresse e a ansiedade tensionam os músculos. Esta tensão retroalimenta a ansiedade mental.

### Ativação parassimpática
O relaxamento muscular profundo ativa o sistema nervoso parassimpático.

## Guia passo a passo

### Preparação
Encontre um lugar tranquilo. Sente-se ou deite-se confortavelmente. Feche os olhos.

### Sequência
Trabalhe dos pés à cabeça. Para cada grupo: tensionar 5-7 segundos, relaxar 15-20 segundos.

### Pés → Pernas → Abdômen → Mãos → Braços → Ombros → Pescoço → Mandíbula → Olhos → Testa

## Dicas para o sucesso

- Não tensione demais — não deve doer
- Preste atenção ao relaxamento
- Mantenha respiração normal
- Pratique regularmente
- Use para dormir
