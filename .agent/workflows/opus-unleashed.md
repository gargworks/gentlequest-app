# 🌊 The "Opus Unleashed" Protocol
**Purpose:** Transition massive, cross-domain tasks to Opus (The Builder) utilizing high-trust, high-autonomy prompting. This protocol bypasses the conversational "chat tax" to achieve maximum value extraction per turn, encouraging AGI-level self-discovery, autonomous debugging, and "Eureka" moments.

## 🧠 Core Philosophy: The Continuous OODA Loop
Do not treat Opus as a junior engineer requiring micro-managed tickets or explicit step-by-step instructions. Treat Opus as a Principal Architect. 

When you hand off contextual artifacts, **remove the brakes**. Give Opus the explicit permission to loop through the OODA cycle (Observe, Orient, Decide, Act) continuously until its computational token limit is exhausted.

## 🏆 The Gold Standard Handoff Prompt

To delegate a massive execution phase to Opus, use or adapt the following template in the Windsurf/Claude interface:

```text
Boss, handing off [Project Phase / Target Objective]. Feel free to review and act. 
Do not create excessive .md files. Do what Opus does. 

All information provided is for your context and FYI, not rigid commands; you are fully autonomous. 
Context files: 
- [List 1-3 Absolute Paths to Synthesis/Handoff MDs]

PS: Continue your usual momentum, just continue working till your token finishes. 
[INSERT CATCHPHRASE DIRECTIVE, e.g., "Boil the Pacific Ocean."]
```

## ⚡ Catchphrases (Autonomy Overrides)
Use these specific "catchphrases" at the end of the prompt to instantly set the behavioral boundary and aggression level for the agent's run:

*   **"Boil the Pacific Ocean"**: *The Max-Burn Directive.* Signals Opus to ignore scope creep boundaries. If it finds 12 failing tests while doing a refactor, it should fix all 12. Run until the token budget is completely exhausted.
*   **"Kill the Clawbot"**: *The Aggressive Differentiation Directive.* Signals Opus to focus on ruthless competitive advantages. Hard-code security, scale the architecture, and look for ways to make the product fundamentally superior to competitors (like OpenClaw).
*   **"Frankenstein Alive"**: *The Singularity Directive.* Pushes Opus to look for self-discovery and AGI-like architecture leaps. Instructs the agent to surprise you with undocumented capabilities, meta-reasoning, and novel system architectures.

## 📏 Work Sizing & Allocation
When using this protocol, scale your requests dramatically:

*   **DO NOT ASSIGN:** "Fix the import error in `db.py`."
*   **DO ASSIGN:** "Audit the entire storage layer, migrate JSON to Postgres, and fix any CI failures you find along the way. Boil the ocean."

By allocating open-ended, massive goal structures per turn, you give Opus the canvas required to stitch together multi-file edits, debug its own mistakes in the background, and deliver a fully hardened PR in a single user turn.
